启动本地程序（开发环境）

数据目录固定为 %APPDATA%\HRPlus，不再跟随安装目录；直接源码运行必须先设置三个环境变量，否则启动时报 console_url 校验失败：

$oldPid = (Get-NetTCPConnection -LocalPort 55271 -State Listen -ErrorAction SilentlyContinue).OwningProcess; if ($oldPid) { Stop-Process -Id $oldPid -Force }
$env:GOODHR_APP_ENV='dev'; $env:GOODHR_CONSOLE_URL='http://localhost:3000/admin'; $env:GOODHR_CLOUD_API_BASE='http://127.0.0.1:8084'
go run ./cmd/goodhr-local-agent --open-console=false

正式安装包由打包工具注入环境配置，无需设置这些变量：
.\packaging\build_windows_installer.ps1 -Environment dev
