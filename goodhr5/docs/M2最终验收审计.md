## 当前必须补齐

1. **整天离线且未上传等待记录的日报。** 云端 `SettleUnstartedWaits` 当前只遍历已登记 waits；本地 `SyncWaitingFacts` 只补传已有队列。电脑整天关机或未运行时，两处都不能产生原日的未执行报告。需使用已确认的原启用批次、配置和日期做记账，不能伪造 TaskRun、开始时间、执行权或动作数量；已有实际领取记录不能被零动作报告覆盖。
2. **候选安装环境。** 现有安装器会写用户 AppData、快捷方式和注册安装记录，并按进程名结束旧程序；更换安装目录不能隔离副作用。不得直接拿用户已安装程序和业务数据作测试。需要完整候选包在独立 Windows 安装环境执行及留存安装后版本/页面/旧入口证据。
3. **最终证据固定。** 上述缺口修复后，按原测试命令跑受影响门槛，固定提交、开发包摘要和九项场景结果，保留真实云端、受控网页、实际程序、安装和生产发布的不同证据边界。

旧版本缺少原配置或原启用事实时，不推测历史岗位和数量，也不以“无法重建”自动关闭原验收要求。生产发布、真实候选人效果和真实邮件投递尚未执行，不包含在现有受控通过结论中。
