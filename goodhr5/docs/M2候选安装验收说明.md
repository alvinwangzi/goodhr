## 安装前必须明确

推荐在独立 Windows 11 测试环境安装。普通 `/DIR` 换目录不能隔离安装器副作用：安装脚本还会结束旧程序进程、写入用户 AppData 控制台、创建快捷方式及安装记录。当前电脑没有找到可直接使用的 Windows Sandbox 命令，因此尚未执行安装。

本轮已向用户确认安装环境，尚未收到选择。没有启动安装器、停止用户程序或接入业务数据库。用户没有回复不视为同意。

若选用当前电脑，须明确允许替换旧本地程序；测试服务和数据仍需隔离，不能沿用真实候选人或真实邮件来完成验收。安装结束时先取消自动启动，确认隔离数据和服务后再启动测试程序，避免恢复用户现有招聘安排。
