### 岗位运行
- 定义：本地 Agent 针对某个招聘岗位执行的自动化流程，包括扫描候选人列表、打招呼、查看在线简历、AI 评分、索要简历、自动回复消息等步骤。一次“岗位运行”对应一个候选人的处理周期，完成后会同步统计（扫描数、打招呼数、跳过数、失败数）到云端。
- 别名：岗位任务、running 状态

### 自动回复
- 定义：本地 Agent 在候选人发起聊天后，基于岗位模板中的提示词、FAQ 语料以及上下文对话，由 AI 自动生成回复消息的功能。与“主动打招呼”是并列的两个动作，可在同一任务中多选开启。
- 别名：AI 自动回复、自动对答

### 求简历
- 定义：Boss 直聘聊天面板上的“求简历”按钮操作，是触发候选人发送附件简历的关键动作。不是从聊天正文里解析文字判断，而是点击聊天框右上角的“附件简历”弹层中的下载按钮才真正下载简历。
- 别名：索要简历、要简历

### 简历库
- 定义：管理系统内的候选人收藏列表，用于跟踪“想要索要简历”的候选人及其状态。当候选人被标记为要简历后，需要同步更新简历库中的相关信息（如是否已收到简历）。
- 别名：候选人库、推荐候选人列表

### 激活码
- 定义：由超级管理员在后台生成的兑换码，用户登录后输入激活码可延长会员天数。激活码有状态（未使用/已使用）、过期天数、使用人邮箱等信息。
- 别名：兑换码、activation code

### 平台账号
- 定义：本地 Agent 绑定的招聘平台账号（如 Boss 直聘主账号），每个平台账号对应一个浏览器 profile，用于隔离不同账号的登录态和操作。
- 别名：platform account、boss 主账号

### Local Agent
- 定义：安装在用户电脑上的 Go 程序（goodhr-local-agent.exe / hrplus-agent.exe），负责控制浏览器操作 Boss 直聘等平台，执行打招呼、自动回复、简历扫描等自动化任务，并通过 WebSocket 与云端后端通信。当前仓库同时保留老版本 `local-agent-go` 和新架构 `local-agent-go-new`，正在迁移中。
- 别名：本地 Agent、本地程序、goodhr-local-agent

### HRPlusL 级
- 定义：新用户首次登录后的欢迎弹窗之一，配合“赠送 3 天会员”弹窗一起出现，用于引导用户使用产品。内容可通过后台超级管理员维护。
- 别名：5L 级弹窗、新手引导弹窗

### 客户端绑定账号
- 定义：将本地安装的 Local Agent 与云端用户账号关联的功能。开发阶段可关闭此开关，以便在一台电脑上安装多个客户端并测试多账号场景。
- 别名：agent binding、客户端绑定

### HR+
- 定义：项目的品牌名称（原名 HR Radar / HRPlus），体现在安装包目录名、进程名、桌面快捷方式图标等位置。打包产物最终命名为 HR+，安装目录统一为 HRPlus。
- 别名：HR Plus、HRPlus、HR+
