### GoodHR 5
- 定义：GoodHR 项目的第五代产品形态，采用“云端控制台 + Windows 本地执行器”的双端架构：云端管理账号、岗位、任务和配置，本地程序负责打开招聘网站、读取候选人并执行筛选与打招呼。
- 别名：goodhr5、GoodHR五

### 云端
- 定义：指 GoodHR 5 的 Web 服务端，包含 Go 后端（API、数据、任务配置）和 Next.js 前端（管理后台），负责账号登录、岗位编排、任务下发和本地 Agent 状态管理。
- 别名：cloud、云端服务

### 本地程序 / 本地 Agent
- 定义：运行在用户 Windows 电脑上的 GoodHR 本地执行器（Go 主进程 + Node Worker），负责打开招聘网站、操控浏览器、读取候选人详情、执行打招呼、截图、OCR 以及保存本地任务数据。
- 别名：local-agent、本地Agent、本地执行器

### 平台
- 定义：GoodHR 适配的外部招聘网站，当前已实现 Boss 直聘、猎聘猎头端，后续扩展智联招聘、猎聘企业端等；每个平台有独立的页面流程实现。
- 别名：招聘平台、platform

### 岗位
- 定义：用户在云端为某个招聘平台配置的招聘职位，包含岗位名称、筛选要求和 AI 提示词等，是任务创建和候选人匹配的基本单位。
- 别名：职位、position

### 任务
- 定义：绑定一个岗位并触发本地 Agent 运行的执行单元，包含平台、账号、开始/停止状态、进度统计等信息；任务可随时停止并在停止时尽量关闭已打开的候选人详情。
- 别名：task、招聘任务

### 候选人
- 定义：招聘网站上被任务扫描到的求职者；系统会对其进行去重、关键词/AI 预评分，达到阈值后才打开详情做最终判断并打招呼。
- 别名：候选、candidate

### 打招呼
- 定义：GoodHR 自动化的核心沟通动作：对符合阈值的候选人在招聘平台聊天框中发送预设消息，是任务流程的最终输出环节。
- 别名：打招呼消息、auto-reply

### 索要简历
- 定义：在候选人对话中点击“索要简历”按钮获取对方附件简历的动作；该动作发生在逐个处理候选人的流程中，并非批量一次性下载。
- 别名：要简历、request resume

### AI 预评分 / 预评分
- 定义：第一轮基于关键词或 AI 分析对候选人进行快速打分，只有超过设定阈值的候选人才会继续读取详情做最终判断，用于减少等待时间。
- 别名：预评分、AI 评分

### 去重
- 定义：对扫描到的候选人进行重复识别与过滤，降低重复查看和重复沟通的概率。
- 别名：重复检查、dedup

### 机器绑定
- 定义：云端记录本地 Agent 所在机器的绑定关系，用于限制一台机器只能被特定云端账号关联，是云端与本地程序的连接管控机制。
- 别名：machine binding

### AI 钱包 / AI 钱包单位
- 定义：GoodHR 5 内部用于计量 AI 调用消耗的虚拟账户体系，包含余额、单位、订单等概念，支撑按次计费或套餐消耗。
- 别名：AI Wallet、ai_wallet

### 邀请激活码
- 定义：用于新用户注册或开通功能的邀请码机制，保存在系统表中并可配合白名单域名使用。
- 别名：invitation code、激活码

### 引导页 / Onboarding
- 定义：新用户首次进入系统时的引导流程，包括引导节点、运行时组件、欢迎确认等，用于帮助用户完成初始配置。
- 别名：onboarding、新手引导
